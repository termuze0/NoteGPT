# 🧠 noteGPT – AI-Powered Note-Taking App

**noteGPT** is an intelligent note-taking web app powered by OpenAI’s GPT models. Take notes, get instant summaries, and stay organized with ease.

## 🚀 Features
- ✍️ Create, edit, and delete notes
- 🤖 AI-generated summaries of your notes
- 🔍 Search and tag notes for better organization
- 🔐 Secure user authentication using JWT
- 📁 Auto-save and cloud synchronization using MongoDB
- 🌙 Light/Dark mode support

##  Tech Stack

**Frontend:**
- React
- Tailwind CSS
- Axios
- React Router

**Backend:**
- Node.js
- Express
- MongoDB + Mongoose
- OpenAI API (GPT-3.5+)
- JWT for authentication
## System-Requirements
- Node.js v16.0.0 or higher
- npm v8+ or yarn v1.22+
- Git v2.30+
- MongoDB (local or Atlas)
- OpenAI API key
- Code editor (VS Code recommended)
- Postman or Hoppscotch (for API testing)
- MongoDB Compass (for DB management)
